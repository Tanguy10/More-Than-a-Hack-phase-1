# X AI technical report — complete C model

## Task and final system

The submission assigns one label to each tactical-video frame: H (home possession), A (away possession), D (dead ball), X (outside the processed periods). It uses the organiser-provided tactical EPTS player positions, team side, speed, measured ball positions and observation masks. Input is 25 Hz on a 105.3 by 68 m pitch. Missing observations remain missing. No video, audio, smart tags, target labels, public evaluation file or cached prediction is an inference feature.

The delivered model is **C**, an ensemble of two complete same-fold networks: a permutation-invariant set encoder and a relational MLP encoder. Each feeds a temporal convolutional backbone, a temporal ball-reconstruction branch and a segment-query decoder. The query decoder has 128 learned queries, six Transformer decoder layers, eight attention heads and a feedforward width of 512. It contributes H/A occupancy and directional transition evidence; the network still jointly predicts H/A/D. The reconstruction retains uncertainty and measured visibility rather than treating an estimated ball as observed.

The set member has 3,308,445 parameters and the relational member 3,375,873. Inference symmetrizes team names, averages state probabilities and boundary probabilities across the pair, then uses the fixed decoder: state temperature 6, change cost 2, boundary weight 0.5. Full-rate Viterbi is run separately within each published period. It uses future context offline; it is not a live causal estimator. No minimum-duration rule is added at delivery time. Missing ball tracking does not automatically imply D.

## Training and provenance

We deliver the complete frozen fold-0 pair, without refitting or changing its selected endpoint. Both members completed 100 epochs / 2,400 updates of the C stage, initialized from the complete same-fold tracking backbone. Dense possession supervision comes from three IDSSE matches: DFL-MAT-J03WN1, DFL-MAT-J03WOH and DFL-MAT-J03WPY. DFL-MAT-J03WQQ is its internal validation match; DFL-MAT-J03WMX and DFL-MAT-J03WOY are outer holdouts. Fourteen SkillCorner matches and twelve SoccerTrack halves (six matches) provide auxiliary supervision. Exact training and initialization match lists, source checkpoint identities, configuration, tensor fingerprints and release checkpoint hashes are in [weights manifest](https://github.com/Tanguy10/More-Than-a-Hack-phase-1/blob/main/model-c/weights/manifest.json).

IDSSE supplies native possession and ball-status references. SkillCorner supervision uses consensus automatic H/A proxies over detected observations; unknown frames remain unlabeled. SoccerTrack uses source contact events for narrow H/A references and reliable out/restart pairs for partial D interiors. These are derived auxiliary labels, not new dense manual annotations. Ball reconstruction uses observed native trajectories with simulated missing observations; event-reconstructed ball coordinates are excluded from SoccerTrack input. See [DATA.md](https://github.com/Tanguy10/More-Than-a-Hack-phase-1/blob/main/model-c/docs/DATA.md) for source citations, licenses and detailed conventions. No manual labels were added to the challenge match. Target labels were not used in training or calibration.

The original training checkpoints are reduced to model tensors and primitive configuration for distribution. Optimizers, random generator state, private paths and training arrays are excluded. Every tensor, including buffers, is verified equal to its source tensor before release. Source provenance records the inference transplant and namespace-only import changes. No runtime training dependency is required.

## Experiments and final choice

The primary development metric is the organisers' Spell F1 averaged over temporal IoU thresholds 0.3 through 0.7. H/A/D macro F1 is secondary. The latest paired CPU comparison contains six development matches under clean, medium and severe conditions: 18 cases per model. C reaches 0.69316335 Spell F1 versus 0.69318765 for the reference. This very small difference is not a demonstrated improvement or proof of equivalence. C improves the severe-condition mean (0.628751 versus 0.613443) while the reference leads on clean input (0.771566 versus 0.758251). Each wins on three of the six matches.

Specialized H/A training, probability calibration and player-only LightGBM fusion were evaluated. Better calibration did not improve final possession segmentation. Replacing C's D emission with LightGBM lowers development Spell F1 to 0.60625337. We therefore deliver C without that fusion. Direct argmax and fixed voting policies also failed in the evaluated comparisons; these findings do not establish universal superiority of Viterbi or isolate a causal architecture effect. [EXPERIMENTS.md](https://github.com/Tanguy10/More-Than-a-Hack-phase-1/blob/main/model-c/docs/EXPERIMENTS.md) records the completed comparisons.

The C checkpoint pair and decoder were fixed before target diagnostics. The team's final choice of C followed diagnostic comparisons, including inspection of the public window; that window is not independent validation and no target-window score is used to claim a full-match gain. No additional tuning or training was performed to prepare this delivery. The public window has only seventeen possessions. All six external development matches have also been reused across research decisions, and the three corruption conditions are correlated. Private full-match quality remains unknown.

## Possession conventions and limitations

Joint H/A/D evidence and temporal boundaries determine possession transitions. Short contact is not forced into a new possession; sustained team control is favoured by the temporal decision rule. The model's labels approximate source possession conventions, which can differ across datasets. Segmentation errors remain possible on brief possessions, contested balls, occlusions, substitutions and incorrect ball observations. Stronger geometry or per-frame accuracy alone does not guarantee higher Spell F1.
